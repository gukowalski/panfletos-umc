# Folders do projeto de extensão

Três sites estáticos, um por pasta:

- nuvem/  → folder-nuvem.onrender.com
- codigo/ → folder-codigo.onrender.com
- lgpd/   → folder-lgpd.onrender.com

No Render: New → Static Site, escolha este repositório, deixe "Build Command" vazio
e em "Publish Directory" coloque o nome da pasta (nuvem, codigo ou lgpd).
